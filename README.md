# EDAFlow

> AI-Powered Conversational Analytics & Business Intelligence Platform

EDAFlow is an intelligent analytics platform designed to transform traditional dashboards into conversational analytical experiences. It combines AI copilots, backend orchestration, intent parsing, and analytics routing to help users interact with data more naturally and efficiently.

The platform evolves beyond static visualizations by enabling conversational workflows, intelligent query understanding, and dynamic insight generation.

---

## 🚀 Features

* 🤖 AI Analytics Copilot
* 🧠 Intent Parsing & Query Understanding
* 🔀 Backend Analytics Orchestration
* 📊 Conversational Data Insights
* ⚡ Dynamic Response Generation
* 🎨 Modern Responsive UI
* 🔗 API-Based Analytical Workflows
* 📈 Interactive Dashboard Experience
* ☁️ Deployment-Ready Architecture

---

## 🏗️ Architecture Overview

EDAFlow follows a backend-orchestrated conversational intelligence architecture.

```text
Frontend UI
     ↓
AI Copilot Interface
     ↓
Intent Parser
     ↓
Analytics Router
     ↓
Response Builder
     ↓
Structured Insights & Visual Outputs
```

Core backend modules include:

* `copilot.py`
* `intent_parser.py`
* `analytics_router.py`
* `response_builder.py`

These modules work together to provide intelligent conversational analytics workflows.

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/Eshhlok/EDA.git
cd EDA
```

### Install Frontend Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm run dev
```

### Backend Setup

```bash
pip install -r requirements.txt
```

### Run Backend

```bash
python app.py
```
